# Ограничения приёмки E11

5–6 ноября 2026 года, `DESKTOP-LSF4GK5`, версия `0.1.0-SNAPSHOT` в ревизии E11.

| Критерий | Фактически | Статус |
|---|---|---|
| SR-04. 4 vCPU, 8 ГБ RAM, SSD 100 ГБ | Ryzen 5 5500U, 6 ядер и 12 потоков. SSD 512,1 ГБ. Windows видит 16,47 ГБ физической памяти, Docker Engine видит 7 976 300 544 байта. Эффективная память ниже минимума. | FAIL |
| PERF-01 и AT-09 | 50 000 счетов, 250 000 исходных операций, 60 независимых сеансов. Три прогона 20/20/60 с. p95 экранов 70 мс. Пилот 300 сеансов, 200 000 счетов и фазы 5/5/20 минут требуют отдельного стенда. | NOT VERIFIED |
| PERF-02 | 90 результатов каждого вида, до 5 одновременно. Максимум 5,040 с, финансовые итоги совпали с SQL. Измерения относятся к сокращённому профилю и прогретой базе. | NOT VERIFIED для пилота |
| UI-01 | Chrome и Firefox не обнаружены. Edge 156.0.4314.58 установлен и запущен. Управление остановилось до открытия проверяемого URL. HTML, CSV и JSON подтверждены серверными проверками. | NOT VERIFIED |
| SR-24 | Изолированное восстановление фактического нагрузочного набора измерено. Пилотный объём 200 000 счетов и 1 000 000 операций требует собственного замера. | NOT VERIFIED для пилота |

Нагрузочный генератор и Docker работали на одном Windows-хосте. Пик CPU хоста составил 100%, процесса генератора — 7,36% в снимках телеметрии. Во время первых фаз часть ресурсов использовали целевые тесты. Docker Desktop и параметры Windows сохранены. Для итоговой оценки нужны подходящий стенд и отдельный либо учтённый генератор. Выводы об аппаратном минимуме основаны на фактическом лимите Docker, а не на установленном объёме RAM.

По итогам выполненных испытаний отдельный локальный коммит фиксирует проверенную ревизию и ограничения. Приёмочный тег появится после подтверждения оставшихся критериев. [Матрица](acceptance.md) · [Профиль и интерпретация метрик](../tests/performance/README.md)
