# Пользовательская инструкция: выписки E8

## Вход и выбор счёта

1. Запустите Docker Desktop и приложение по README. Откройте `https://localhost:8443/login`.
2. Войдите своей учётной записью. Учебные логины имеют вид `demo-admin`, `demo-operator`, `demo-accountant`, `demo-manager`, `demo-client`; пароли хранятся только в локальном `.env`.
3. Сотрудник открывает «Счета» и нужную карточку. Клиент выбирает «Мои счета» и свой счёт. Нажмите «Сформировать выписку».

Администратор читает выписки, но не проводит деньги. Оператор работает с карточками и счетами, бухгалтер — с финансовыми операциями, руководитель читает данные. Эти различия сохраняются: открытие выписки не даёт новых прав изменения. Клиент видит исключительно свои счета. Закрытый или приостановленный счёт можно просматривать, если у пользователя есть разрешение.

## Период и содержание документа

Укажите обе даты и нажмите «Сформировать выписку». Граничные даты включаются. Максимум — 366 дней включительно. Начальная дата не должна предшествовать началу доступной истории, показанному над формой. При ошибке исправьте даты и сформируйте документ снова.

На документе показаны счёт, владелец, период, время формирования и валюта RUB. Входящий остаток учитывает все проведённые операции до выбранного периода. Далее идут только проведённые движения периода; черновики в выписку не входят. Порядок: дата учёта, время проведения, UUID по возрастанию. Исправление сохраняет ссылку на исходную запись и показывает собственное влияние на остаток.

- Начисление увеличивает задолженность.
- Платёж уменьшает задолженность.
- Исправление меняет её на собственную знаковую delta.
- «Увеличение» складывает положительные delta, «уменьшение» — абсолютные значения отрицательных.
- Исходящее сальдо = входящее + увеличение − уменьшение. Плюс означает долг, минус — переплату.

Период без движений — допустимая выписка с нулевыми оборотами и одинаковыми остатками. Движения после периода не влияют на его итог, даже если текущее сальдо счёта уже изменилось.

## Печать и сохранение

«Изменить период» возвращает к параметрам. «Печать» открывает представление без лишней навигации; кнопка печати вызывает диалог браузера, где можно выбрать принтер или сохранение в PDF. «Скачать CSV» сохраняет полный документ в UTF-8 с BOM и разделителем `;`, пригодный для Windows. «Получить JSON» открывает структурированные данные в текущем защищённом сеансе.

Не вводите пароли в адресную строку и не передавайте cookie другим людям. При попытке открыть чужой счёт клиент получает 403 без его реквизитов. Для нового финансового примера используйте отдельный счёт; чтение/экспорт выписки само по себе не меняет операции или остатки.

Форматы используют единый расчёт. Если бухгалтер провёл новую запись между двумя открытиями, новый документ может отличаться. Для сравнения печати, CSV и JSON выберите один и тот же период и не проводите операции между запросами. Формат и поля экспорта описаны в `api.md`.
