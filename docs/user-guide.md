# Руководство пользователя

Для защиты используйте `https://localhost:18450/login` и пароли из `.local\defense.env`. Рабочее приложение открывается по `https://localhost:8443/login`. Финансовые примеры создавайте в отдельном демонстрационном контуре. Команды запуска и контрольный сценарий приведены в [инструкции демонстрации](demo.md).

После входа слева расположено меню разделов, сверху показаны путь к странице, пользователь, роль и кнопка «Выйти». Активный раздел выделен. На узком экране меню открывается отдельной кнопкой. Переход «К содержимому» позволяет сразу попасть к основной части страницы с клавиатуры.

| Раздел | Что открывается |
|---|---|
| Главная | Действия и данные, доступные вашей роли |
| Пользователи | Учётные записи и доступ, только для администратора |
| Клиенты | Реестр сотрудников или собственная карточка клиента |
| Лицевые счета | Реестр счетов или собственные счета клиента |
| Финансовые операции | Выбор счёта и переход к его истории |
| Выписки | Выбор счёта и периода документа |
| Финансовые отчёты | Четыре отчёта для администратора, бухгалтера и руководителя |
| Журнал действий | Разрешённые события для администратора и руководителя |

На главной странице администратора расположены переходы к пользователям и журналу. Оператор получает действия для карточек клиентов и открытия счетов. Бухгалтер может перейти к операциям и вернуться к пяти последним собственным черновикам. Руководитель открывает отчёты и журнал. Клиент видит первые 20 собственных счетов с остатками и переходами к истории и выпискам. Общее число счетов и ссылка на полный список помогают открыть остальные страницы.

Суммы показываются с разделением тысяч и десятичной запятой, например `1 250,00 ₽`. Положительное сальдо означает задолженность, отрицательное — переплату. Статусы подписаны словами. Пустой список предлагает изменить фильтры или выполнить доступное действие.

Для работы с карточками и счетами используйте поиск, откройте строку нужного клиента или номер счёта. Оператор создаёт и изменяет карточки клиентов и открывает счета. Бухгалтер готовит начисления, платежи и корректировки. Перед проведением он проверяет отдельную страницу подтверждения. Администратор читает финансовые документы, руководитель читает разрешённые данные. Клиент открывает только собственные данные. Правила проведения и подтверждения описаны в [сценарии демонстрации](demo.md).

При создании учётной записи с ролью «Клиент» администратор выбирает существующую активную карточку по имени. В форме с паролем дополнительный поиск без JavaScript расположен отдельно. Учётная запись для входа и карточка клиента создаются отдельными действиями.

## Выписка по счёту

Откройте «Выписки», выберите счёт и задайте даты начала и окончания. Выписку также можно открыть из карточки счёта. Обе даты входят в период. Максимальный период составляет 366 дней, а дата начала должна попадать в доступную историю счёта. При ошибке исправьте поля и отправьте форму снова.

Документ показывает счёт, владельца, период и время формирования. Четыре карточки содержат входящее сальдо, увеличение и уменьшение задолженности и исходящее сальдо. В таблицу попадают проведённые движения периода. Корректировка сохраняет связь с исходной записью. Её технические реквизиты можно раскрыть отдельно.

Входящий остаток учитывает операции до периода. Исходящее сальдо равно входящему плюс увеличение за вычетом уменьшения. Период без движений допускается и даёт нулевые обороты с одинаковыми входящим и исходящим остатками. Движения после выбранного периода не меняют его итог.

«Изменить период» возвращает к форме. «Скачать CSV» сохраняет документ. «Версия для печати» открывает документ для печати, кнопка «Печать» вызывает стандартный диалог браузера. В блоке «Для интеграции» доступен JSON.

## Финансовые отчёты

1. Войдите как администратор, бухгалтер или руководитель и откройте «Финансовые отчёты».
2. Выберите вкладку «Начисления», «Платежи», «Задолженность» или «Движение по счетам».
3. Укажите месяц для первых двух видов, одну дату для задолженности либо начало и конец периода для движения.
4. Для одного клиента введите имя или название в поле «Клиент» и выберите совпадение. Список ограничен 20 результатами. Если нужного клиента нет, уточните запрос. С клавиатуры используйте стрелки и Enter, Escape закрывает список.
5. Без JavaScript нажмите «Найти», затем «Выбрать» рядом с клиентом. Форма сохранит период и остальные фильтры.
6. Укажите текущий статус счёта и число строк от 1 до 100, затем нажмите «Сформировать отчёт».

Пустое поле клиента включает всех клиентов. «Сбросить» очищает выбор клиента, «Сбросить фильтры» возвращает форму к исходным значениям выбранного вида отчёта. После редактирования имени клиента выберите результат заново. Имя выбранного клиента показывается в параметрах результата.

| Отчёт | Как читать результат |
|---|---|
| Начисления | Исходные начисления и их корректировки за месяц образуют чистые начисления |
| Платежи | Исходные зарегистрированные платежи и поправки к ним образуют чистые платежи |
| Задолженность | Долг и авансы суммируются по счетам отдельно, чистое сальдо равно их разности |
| Движение | Входящее сальдо, движения периода и исходящее сальдо позволяют проследить изменение задолженности |

Итоговые карточки относятся ко всем счетам, подходящим под фильтры. «Назад» и «Далее» меняют страницу деталей, сохраняя общие суммы. Номер счёта открывает его карточку. При отсутствии строк можно вернуться к фильтрам.

«Скачать полный CSV» включает все подходящие строки. Печатная версия содержит детали текущей страницы и общие итоги по всему отчёту. Пояснение об этом включено в документ. JSON доступен в раскрываемом блоке «Для интеграции».

## Таблицы, печать и сохранение

Широкую таблицу можно прокрутить внутри её области. Для клавиатуры переведите фокус на таблицу клавишей Tab, затем используйте горизонтальные стрелки. Фокус выделяется рамкой. На узком экране меню скрывается за кнопкой, а таблица сохраняет заголовки и значения.

При печати выписки или отчёта навигация и кнопки скрываются. Документ подготовлен для A4 в альбомной ориентации. Перед сохранением в PDF или отправкой на принтер проверьте страницы в предпросмотре. Для полного отчёта с большим числом строк используйте CSV, поскольку печать показывает текущую страницу деталей.

CSV использует UTF-8 с BOM и разделитель `;`. Денежные значения в CSV и JSON сохраняют точный машинный формат с десятичной точкой. Если между открытиями бухгалтер провёл новую запись, новый документ может отличаться. Для сравнения форматов используйте одинаковые фильтры и стабильный набор операций. [Контракты экспорта](api.md)

При отказе доступа используйте разрешённые разделы своей роли. Если данные временно недоступны, повторите запрос после восстановления сервиса. Пароли вводятся в форме входа. После работы завершите сеанс кнопкой «Выйти».

## Проверочное восстановление

Для учебной проверки администратор открывает `https://localhost:18443/login`. Используйте учётные данные, действовавшие на дату снимка, и выполните новый вход. Проверьте контрольный счёт, выписку и отчёт на даты из протокола. Команды резервирования и восстановления приведены в [операционной инструкции](admin-guide.md).

Состояние PERF-01, PERF-02 и AT-09 сохраняется как NOT VERIFIED. Исторические протоколы E11 от 06.11.2026 и результаты текущего редизайна учитываются отдельно. [Матрица приёмки](acceptance.md) · [Отчёт о переработке интерфейса](ui-redesign.md)
